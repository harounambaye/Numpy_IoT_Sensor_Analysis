# Numpy_IoT_Sensor_Analysis

##  Description

Projet d’analyse de données de capteurs IoT avec **NumPy**.
L’objectif est de manipuler, explorer et analyser des données de température afin d’identifier des valeurs anormales et de préparer les données pour une future utilisation en **Machine Learning**.

###  Technologies

* Python
* NumPy
* Jupyter Notebook

###  Notions abordées

* Création et manipulation de tableaux NumPy
* Indexation et slicing
* Filtrage booléen
* Statistiques descriptives
* Manipulation des dimensions
* Concaténation
* Broadcasting
* Normalisation et standardisation
* Détection d’anomalies
